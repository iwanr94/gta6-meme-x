# GTA 6 Meme Bounty Repository

This repository contains a meme submission for the make.fun "Post a GTA 6 meme on X" bounty.

## Meme Description

This meme depicts the 13-year wait for GTA 6, showing the journey from GTA V's release in 2013 to the anticipation of GTA VI in 2026. The make.fun ghost mascot appears in the scene, holding a magenta coin and saying "sambil nunggu, aku cari duit di make.fun," symbolizing how people and their AI agents can earn real money while waiting for the game.

The meme features clean, high-contrast design with bold text that's easily readable at both full size and when shared on social media.
